    Six terms, plainly defined
    API
    A defined way for one piece of software to ask another for data or actions.
    Endpoint
    One specific address within an API, dedicated to one kind of question.
    Request
    The message your app sends: which endpoint, which method, which parameters.
    GET method
    The most common request type — read data without changing anything.
    JSON
    A plain-text data format using { }, [ ], and "key": value pairs.
    Status code
    A 3-digit summary of what happened — 200 success, 4xx your mistake, 5xx server's.
    A self-contained file — every request above goes directly from your browser to Open‑Meteo's public API (CC BY 4.0). No accounts, keys, frameworks, or external dependencies of any kind.
